## 📌 وصف المشروع (Project Overview)

مشروع **توقع أداء الطلاب (Student Performance Predictor)** هو نظام تعلم آلة تطبيقي مبسط ومتكامل يهدف إلى توقع **درجة الطالب المتوقعة في الاختبار النهائي من 0 إلى 100**، بالاعتماد على مجموعة محددة ومركزة من العادات الدراسية والعوامل السلوكية.

### 🎯 أهداف المشروع الرئيسية:
1. **تطبيق خطوات تعلم الآلة القياسية**: تنفيذ مسار تعلم آلة سليم هندسياً وعلمياً من مرحلة استكشاف البيانات وحتى نشر النموذج في واجهة تفاعلية.
2. **منع تسريب البيانات (No Data Leakage)**: تقسيم البيانات إلى ثلاثة أقسام منفصلة (تدريب، وتحقق، واختبار)، وتطبيق المعالجة المسبقة داخل خطوط أنابيب (`Pipeline`) موحدة.
3. **المقارنة العلمية الصادقة**: مقارنة النماذج مع خط أساس عشوائي (`DummyRegressor`) والتحقق من تفوق نموذج تعلم الآلة قبل اعتماده.
4. **تبسيط تجربة المستخدم**: توفير واجهة ويب عربية تفاعلية وسلسة مبنية بواسطة **Streamlit** تمكن الطالب من سحب أشرطة العادات الدراسية والحصول على درجته المتوقعة ونصائح توجيهية فورية.
5. **الابتعاد عن التعقيد الزائد**: التركيز على جوهر تعلم الآلة التطبيقي بدون استخدام شبكات عصبية عميقة أو قواعد بيانات معقدة أو واجهات برمجية خارجية غير ضرورية.

## 📊 مجموعة البيانات والمتغيرات (Dataset & Features)

تم استخدام مجموعة البيانات المعتمدة `StudentPerformanceFactors.csv` الموجودة داخل مجلد [`data/`](data/StudentPerformanceFactors.csv).

### **متغير الهدف (Target Variable - $y$):**
- **`Exam_Score`**: درجة الاختبار كقيمة رقمية محصورة بين **0 و 100**.

### **المتغيرات المدخلة المختارة (Input Features - $X$):**

| المتغير (Feature) | النوع (Type) | الوصف (Description) | النطاق / القيم (Values) |
| :--- | :--- | :--- | :--- |
| **`Hours_Studied`** | رقمي (Numerical) | عدد ساعات المذاكرة أسبوعياً | 1 إلى 44 ساعة |
| **`Attendance`** | رقمي (Numerical) | نسبة حضور الحصص والمحاضرات | 60% إلى 100% |
| **`Previous_Scores`** | رقمي (Numerical) | معدل درجات الطالب في الاختبارات السابقة | 50% إلى 100% |
| **`Sleep_Hours`** | رقمي (Numerical) | متوسط ساعات النوم يومياً | 4 إلى 10 ساعات |
| **`Tutoring_Sessions`** | رقمي (Numerical) | عدد جلسات التقوية الإضافية شهرياً | 0 إلى 8 جلسات |
| **`Motivation_Level`** | فئوي (Categorical) | مستوى دافعية وحماس الطالب | `Low` (منخفض), `Medium` (متوسط), `High` (عالي) |
| **`Extracurricular_Activities`** | فئوي (Categorical) | المشاركة في الأنشطة الطلابية واللاصفية | `Yes` (نعم), `No` (لا) |

## 🛠️ التوثيق الفني وخطوات تعلم الآلة (Technical Documentation)

```
بيانات CSV الأصلية (StudentPerformanceFactors.csv)
       │
       ▼
[1] استكشاف وفهم البيانات (Understand the Data)
       │ ── فحص الأبعاد (6607 صفاً × 20 عموداً)
       │ ── استخراج الإحصائيات الوصفية وتوزيع القيم
       ▼
[2] جودة البيانات والتنظيف (Data Quality & Cleaning)
       │ ── فحص القيم المفقودة (0% في المتغيرات المختارة)
       │ ── فحص التكرارات (لا توجد صفوف مكررة بالكامل)
       │ ── معالجة القيمة غير المنطقية (Exam_Score = 101 تم حصرها في 100)
       ▼
[3] تقسيم البيانات الثلاثي (3-Way Split with random_state=42)
       ├── 70% بيانات التدريب (Training Set - 4,624 عينة) ──► تدريب النماذج
       ├── 15% بيانات التحقق (Validation Set - 991 عينة)  ──► مقارنة النماذج واختيار الأفضل
       └── 15% بيانات الاختبار (Test Set - 992 عينة)        ──► التقييم النهائي المستقل
       ▼
[4] المعالجة المسبقة داخل Scikit-learn Pipeline
       ├── المتغيرات العددية: SimpleImputer(median) + StandardScaler()
       └── المتغيرات الفئوية: SimpleImputer(most_frequent) + OneHotEncoder(ignore)
       ▼
[5] تدريب النماذج ومقارنتها
       ├── النموذج المرجعي (Baseline): DummyRegressor (التوقع بالمتوسط)
       ├── النموذج الأول: الانحدار الخطي (Linear Regression)
       └── النموذج الثاني: الغابات العشوائية (Random Forest Regressor)
       ▼
[6] تقييم الأداء واختيار النموذج البطل (Champion Model)
       │ ── المقاييس: MAE (متوسط الخطأ المطلق), RMSE (جذر متوسط مربع الخطأ), R² Score
       ▼
[7] التقييم النهائي المستقل على بيانات الاختبار وحفظ النموذج (.joblib)
       ▼
[8] النشر في واجهة مستخدم تفاعلية ومبسطة عبر Streamlit
```

### 1. معالجة البيانات المسبقة (Preprocessing Pipeline):
تم توحيد المعالجة المسبقة باستخدام `ColumnTransformer`:
- **المتغيرات العددية**: تعويض القيم المفقودة بالوسيط الحسابي (`SimpleImputer(strategy='median')`)، ثم التوحيد القياسي (`StandardScaler`) لتسوية مقاييس المتغيرات دون تسريب.
- **المتغيرات الفئوية**: تعويض القيم المفقودة بالأكثر تكراراً (`SimpleImputer(strategy='most_frequent')`)، ثم الترميز الثنائي (`OneHotEncoder(handle_unknown='ignore')`).

### 2. نتائج مقارنة النماذج على بيانات التحقق (Validation Set Results):

| النموذج (Model) | MAE (درجة) | RMSE (درجة) | معامل التحديد ($R^2$) | الحالة والتقييم |
| :--- | :---: | :---: | :---: | :--- |
| **Dummy Regressor (خط الأساس)** | 2.7634 | 3.5298 | -0.0011 | نموذج بدائي مرجعي للتأكد من جدوى تعلم الآلة |
| **Linear Regression (الانحدار الخطي)** | **1.2238** | **2.0444** | **0.6642** | 🏆 **النموذج البطل (أقل خطأ وأعلى دقة)** |
| **Random Forest Regressor** | 1.4263 | 2.3354 | 0.5618 | نموذج شجري مرن لكنه تأثر بالضوضاء الإحصائية |

### 3. التقييم النهائي للنموذج البطل على بيانات الاختبار غير المرئية (Test Set):

| النموذج الفائز (Champion Model) | Test MAE | Test RMSE | Test $R^2$ Score |
| :--- | :---: | :---: | :---: |
| **Linear Regression Pipeline** | **1.2417** | **2.3214** | **0.6409** |

> **استنتاج علمي وتفسير هندسي:**  
> تفوق نموذج الانحدار الخطي على الغابات العشوائية في هذه المسألة لأن العلاقة الأساسية بين معدل الحضور، وساعات المذاكرة، والدرجات السابقة تتبع نمطاً خطياً واضحاً. لذا فإن النماذج الخطية البسيطة والمفسرة استطاعت التعميم بشكل أفضل وتجنبت الإفراط في مطابقة الضوضاء (Overfitting).

## 💻 آلية تشغيل واستخدام المشروع (Setup & Usage Guide)

### 1. متطلبات التشغيل (Prerequisites):
- تثبيت بايثون الإصدار 3.10 أو أحدث (`Python >= 3.10`).

### 2. تثبيت الحزم المطلوبة (Install Dependencies):
افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:
```bash
pip install -r requirements.txt
```

### 3. تشغيل مسار التدريب الآلي الكامل عبر الطرفية (Run ML Training):
لتشغيل خطوات التعلم الآلي العشر كاملة من فحص البيانات وتنظيفها وتدريب النماذج وطباعة جداول المقارنة وحفظ ملف النموذج:
```bash
python train.py
```

### 4. تشغيل واجهة المستخدم التفاعلية (Run Streamlit Web App):
لتشغيل الواجهة الرسومية المبسطة الموجهة للطلاب:
```bash
streamlit run app.py
```
ثم افتح الرابط التالي في المتصفح:
👉 `http://localhost:8501`

### 📱 كيفية استخدام الموقع من قبل الطالب:
1. يفتح الطالب الصفحة فيظهر له عنوان تفاعلي: **حاسبة توقع درجة الاختبار**.
2. يقوم بسحب أشرطة التمرير لاختيار:
   - ساعات المذاكرة الأسبوعية.
   - نسبة حضوره المدرسي (%).
   - معدل درجاته السابقة (%).
   - عدد جلسات التقوية ودروس الدعم.
   - ساعات النوم اليومية ومستوى الحماس والمشاركة في الأنشطة.
3. تظهر **الدرجة المتوقعة فوراً** داخل بطاقة أنيقة (مثال: `84.5 من 100`) مع التقدير الدراسي (`ممتاز أ`، `جيد جداً ب`، إلخ).
4. تظهر نصيحة توجيهية فورية مخصصة تشرح للطالب العامل الأهم الذي يمكنه تحسينه لرفع درجته.
